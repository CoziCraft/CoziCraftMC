# Commands

This page is a public home for useful CoziCraft commands. Keep command names current as plugins and server settings change.

## Starter Commands

- `/spawn` returns to the server spawn if enabled.
- `/help` lists available commands.
- `/msg <player> <message>` sends a private message if enabled.
- `/tpa <player>` requests teleportation if enabled.
- `/sethome` and `/home` can be documented here if homes are enabled.

## Maintainer Notes

Before publishing command details, verify the command exists on the live server and confirm any rank restrictions.
