# Troubleshooting

If you cannot connect, start with the simple checks before asking staff for help.

## Connection Checklist

- Confirm you are using Minecraft Java Edition.
- Confirm your version is `26.2`.
- Confirm the server address is `play.cozicraftmc.com`.
- Restart Minecraft and try again.
- Check whether the server has a posted maintenance notice.

## When Asking For Help

Share your Minecraft version, the exact error message, and what you already tried. Do not post account passwords, session tokens, or private launcher logs in public channels.
