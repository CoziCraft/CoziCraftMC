# Events

Events bring the community together without turning the site into a calendar app.

## Good Event Page Content

- Event name
- Date or cadence
- How to join
- Rules or entry requirements
- Rewards, if any
- A short recap after the event ends

## Future Ideas

Build contests, seasonal spawn updates, treasure hunts, and community projects can all live here once the server schedule is ready.
