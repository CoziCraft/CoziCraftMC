# FAQ

## What is the server address?

Use `play.cozicraftmc.com` in Minecraft Java Edition.

## What Minecraft version should I use?

CoziCraft is currently on Java `26.2`.

## Is this Bedrock compatible?

V1 content is written for a Java server. Add Bedrock or cross-play notes only if the server team confirms support.

## How do wiki edits work?

For v1, content is edited in this repository through GitHub. Trusted maintainers can update markdown files and review pull requests.

## Does the store work yet?

Not yet. The site has a public store page and a future Tebex link slot, but no purchases are handled inside this app.
